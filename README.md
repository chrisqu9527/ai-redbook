## 🎯 为什么要写这本红宝书？

市面上已经有很多几百页的 AI 知识库，但新手点进去往往只做两件事：**收藏 → 吃灰**。
这本红宝书反过来做，只守三条死规矩：

1. **只走一条主线**：不当资料大杂烩，按 6 个关卡顺着做，每章结束手里多一件能用的作品。
2. **每个场景只推 1 个工具**：优先国内顺畅可用，帮你治好选择困难症。
3. **常青层 + 时效层分离**：底层心法长期有效，工具推荐与红黑榜按月体检更新并标明版本号（当前 `v2026.11`）。

## 🛠️ 本地运行与开发

```bash
# 1. 安装依赖
npm install

# 2. 启动本地预览服务（默认打开 http://localhost:5173）
npm run dev

# 3. 打包生成静态网站文件
npm run build
```
