# 每日妙用数据

网站页面 `/daily` 读这个文件夹。一天一个文件，文件名 `YYYY-MM-DD.json`。

收的不是“哪个模型又更新了”，而是**普通人用 AI 解决了什么实际问题**：看不懂的体检报告、写不出的请假条、理不清的家庭账单、孩子作业辅导、租房合同查坑……每条讲清楚遇到什么事、怎么用 AI 解决、用哪个国内工具、可以照抄的那句话。

## 流程

1. **Grok Bot** 每天早上在 X 和网页上找别人分享的 AI 实用案例，写 `YYYY-MM-DD.json`，`status` 填 `"draft"`，开 PR（分支 `hot/YYYY-MM-DD`）。
2. **Claude 审稿**：打开原帖核实，换成国内工具能照做的版本，改成大白话，删掉做不到的，`status` 改成 `"published"`，合并。
3. 合并后 Cloudflare Pages 自动部署。只有 `"published"` 的文件会显示在网站上。

## 格式

```json
{
  "date": "2026-11-20",
  "status": "draft",
  "items": [
    {
      "title": "看不懂体检报告，让 AI 逐项翻译",
      "scene": "生活",
      "problem": "体检报告一堆箭头和缩写，挂号问医生要排队，自己查又越查越慌。",
      "how": "把报告拍照发给 AI，让它逐项说明偏高偏低是什么意思、哪些要复查、该挂哪个科。它只能帮你看懂，不能替代医生。",
      "prompt": "这是我的体检报告，请逐项告诉我异常指标是什么意思，哪些需要复查，应该挂什么科。用大白话说。",
      "tool": "豆包",
      "domestic": "能用",
      "price": "免费",
      "source_name": "X @某某",
      "source_url": "https://x.com/...",
      "heat": "收藏 3000",
      "lesson": "/01-start/02-mindset-and-prompts"
    }
  ]
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `title` | 是 | 24 字以内，“遇到的事 + 怎么解决”，不用感叹号 |
| `scene` | 是 | `工作` / `生活` / `学习` / `带娃` / `副业` / `健康` / `理财` |
| `problem` | 是 | 谁遇到了什么麻烦，60 字以内 |
| `how` | 是 | 怎么用 AI 解决，照着能做，120 字以内 |
| `prompt` | 否 | 能直接复制的一段话，150 字以内 |
| `tool` | 是 | 推荐的工具，国内优先 |
| `domestic` | 是 | 这个工具 `能用` / `要梯子` / `不能用` |
| `price` | 是 | `免费` / `部分免费` / `收费` |
| `source_name` | 是 | 原分享者或网站名 |
| `source_url` | 是 | 原帖链接，必须能打开 |
| `heat` | 否 | 热度，原样写数字 |
| `lesson` | 否 | 对应的红宝书课程路径 |

每天 3 到 6 条。检查格式：`node scripts/check-hot.mjs`。
