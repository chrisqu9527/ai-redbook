## 二、别背参数表，把不同模型当成“不同性格的员工”

选工具最容易掉进“跑分对比”的坑。忘掉那些看不懂的英文榜单，记住三个职场角色就够了：

* **靠谱资深主笔型（Claude 系列）**：文字审美最像真人，最懂怎么去掉官话和翻译腔，适合写深度长文、制定复杂写作规范。
* **全能猛将研究员型（Gemini 系列）**：记忆容量极大，看图看视频看整本书不费劲，执行极快——但脾气像刚毕业的“愣头青”，不先摁住它写方案就容易瞎干。
* **高性价比本土尖子生（DeepSeek / Kimi / 豆包）**：国内直连不折腾，免费额度大方，中文语境和日常办公 80% 的活完全扛得住。

## 三、新手花钱避坑三条铁律

1. **前 14 天一分钱都别充！** 先用免费版把第一关到第三关跑通，确认自己真的每周都在高频用，再考虑付费。
2. **拉黑所有“99 元终身全能 AI 合集”套壳软件**：99% 都是二道贩子，要么后台偷偷降级成廉价模型，要么用两个月跑路。认准官网，绝不买来路不明的聚合壳。
3. **只按月付，绝不按年付**：AI 行业半年洗一次牌，今天的神器半年后可能就被新工具吊打，按月付费随时能换。
