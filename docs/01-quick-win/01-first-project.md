# 01. 20 分钟做出你的第一个惊艳作品

<ChapterMeta difficulty="★☆☆ 新手必做" duration="20 分钟" layer="常青层" version="v2026.11" status="已发布" />

很多人打开 AI 的第一周，只干过一件事：问它“帮我写一份周报”或者“给我讲个笑话”。看完觉得“也就这样嘛”，然后就把网页关了。

为了打破这个偏见，**第一关我们不讲任何理论，先花 20 分钟亲手做出一件能直接惊艳同事和朋友圈的作品**——让你亲眼见识一下，不懂一行代码的普通人，到底能让 AI 交出什么级别的成品。

---

## 1. 本章做出什么？

把一段乱七八糟的**会议纪要 / 读书笔记 / 自我介绍 / 活动通知**，在 20 分钟内变成一张**杂志级排版的高清视觉信息卡片（可交互网页，直接截图发小红书/朋友圈，或当汇报单页）**。

你将拿到的成品长这样：
* 暖米白纸感底色 + 高级朱砂红重点标注（绝不是默认丑丑的白底黑字）
* 自动提炼核心金句、3 个关键要点、行动清单与底部署名标签
* **无需安装任何软件、无需会写代码**，点一下就能看到成品并存成图片

## 3. 保姆级操作步骤（一步不跳）

### 第一步：准备一段“乱素材”（2 分钟）
找一段你手头真实的文字（工作总结、读书摘录、或者你想发小红书的干货碎碎念）。如果手头暂时没有，直接复制下面这段测试素材练手：

```text
今天复盘了一下为什么很多人学AI学不会：一是天天收藏几百个工具网址，光收藏不打开；二是把AI当成百度搜几个字就想要完美答案，稍微不满意就觉得AI很蠢；三是总想一口吃成胖子，连基础对话还没摸熟就去折腾写代码。其实最好的办法就是先挑一件你每天都在干的烦心事，只选一个国内好用的工具，连续用一周，把这一件事跑顺了，比收藏100个教程都有用。
```

### 第二步：打开 DeepSeek，一次性粘贴下方提示词（3 分钟）
1. 打开 `https://chat.deepseek.com`，新建一个对话。
2. 建议点亮输入框下方的 **「深度思考（R1）」**（排版审美和信息提炼会明显高一档）。
3. 复制第 4 节的「一键复制提示词」，把最底部的 `【把你的原始文字粘贴在这里】` 替换成第一步的素材，发送！

### 第三步：一键看成品（2 分钟）
* 等待约 30 秒，DeepSeek 会输出一段代码。**千万别被代码吓到，你一个字都不用看懂！**
* 在代码块的右上角，直接点击 **「运行 HTML」**（或预览按钮），一张设计感拉满的高级杂志信息卡片就会立刻弹出来！

::: tip 💡 如果你的浏览器没看到“运行 HTML”按钮怎么办？（100% 兜底方案）
1. 点击代码块右上角的 **「复制」**；
2. 在电脑桌面右键新建一个文本文档（`新建文本文档.txt`），粘贴进去并保存；
3. 把文件名改成 **`card.html`**（注意把 `.txt` 改成 `.html`），直接双击用浏览器打开，同样能看到完美成品！
:::

### 第四步：像甲方一样提 1 轮修改意见（5 分钟）
看一眼成品，如果觉得字太小、标题不够抓人、或者想换配色，**直接用大白话在对话框里接着改**，千万别自己去改代码！比如直接回它：
> “整体不错，帮我改两处：1）主标题再大一点、更有冲击力；2）把底部的标签改成‘公众号：AI博物志’；3）卡片宽度收窄到 480px，方便我直接截图发手机端。请输出修改后的完整代码。”

### 第五步：保存成高清图片（1 分钟）
按微信截图（`Alt + A`）或系统截图快捷键，把这张精致的卡片截下来——你的第一个 AI 成品诞生了！

## 4. 一键复制提示词（已实测防丑化）

把下面整段框里的内容直接复制发给 AI：

```markdown
你是一位拿过国际平面设计奖的视觉编辑，擅长把零散的文字提炼成“高质感杂志风”的知识信息卡片（适合发小红书、朋友圈或公众号配图）。

请把我下面提供的【原始文字】，制作成一个单文件、可直接在浏览器打开预览的 HTML 信息卡片。

【内容提炼要求】
1. 提炼一个抓眼球的主标题（14字以内）和一句副标题。
2. 把核心观点拆成 3 个结构清晰的模块，每个模块配一个简短有力的小标题 + 2行以内大白话解释，坚决删除废话。
3. 在底部提炼 1 句适合读者截图保存的“核心金句”。

【视觉设计死规矩（必须严格遵守）】
1. 画布背景用柔和浅灰（#F3F1EC），中间是一张宽度 480px、圆角 16px 的竖版信息卡片，卡片底色为暖米白（#FCFBF8），带细腻柔和阴影。
2. 配色克制高级：主文字深炭灰（#1F1F1F），辅助文字暖灰（#666666），点缀色统一用高级朱砂红（#C93B2B），禁止出现花里胡哨的霓虹渐变色。
3. 排版要有“呼吸感”：充足的留白（内边距至少 32px）、清晰的数字序号标签（01 / 02 / 03）、细腻的虚线分割。
4. 字体优先调用系统优雅无衬线字体（PingFang SC, Microsoft YaHei），所有样式写在 <style> 里，不依赖外部收费资源，确保离线也能完美显示。
5. 卡片最底部右下角加上一行小字署名：“整理自 · 我的 AI 实战笔记”。

请直接输出完整的、可直接运行的 HTML 代码，不要省略任何部分。

【原始文字】：
【把你的原始文字粘贴在这里】
```

## 5. 真实翻车与避坑（小白最常遇到的 3 个坑）

### 翻车 1：AI 偷懒，代码写到一半用 `// ...其余省略` 糊弄你
* **原因**：当你让它修改第二轮、第三轮时，大模型为了省字数，经常只给你片段代码，导致你点“运行”后页面残缺。
* **一招救场**：每次提修改意见，结尾永远补一句：**“请输出可直接运行的完整 HTML 代码，严禁省略任何部分。”**

### 翻车 2：字堆成一团，像贴满小广告的电线杆
* **原因**：你喂进去的原始素材太长（比如 2000 字），又没逼它做删减。
* **一招救场**：直接回它：**“文字太密了，帮我把总字数再砍掉一半，只保留最核心的 3 个要点，增加卡片留白。”**

### 翻车 3：改电脑后缀时，改成了 `card.html.txt` 打不开
* **原因**：Windows 默认隐藏了文件扩展名。
* **一招救场**：打开任意文件夹 → 顶部菜单点「查看」→ 勾选「文件扩展名」，再改名；或者直接用 DeepSeek / Claude 自带的在线“运行 HTML”按钮，彻底不用碰本地文件。
