# 09. 大白话讲透 Skill、Workflow 与 Agent

这里是普通人用 AI 真正拉开差距的分水岭。本章用“开一家公司”的大白话比喻，彻底讲透：
- **Skill** = 岗位说明书（把你的经验固化成文件，不用每次重复教）
- **Workflow** = 流水线制度（把几个步骤串起来自动往下走）
- **Agent** = 能自己看文件、调工具、按流程把活干完的数字员工
:::
